# notefeed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A self-hosted Next.js app that stores posted markdown notes as `.md` files and serves them as a public RSS feed, with a token-protected web UI and HTTP API.

**Architecture:** Three plain TypeScript modules own all logic — `lib/notes.ts` (disk), `lib/auth.ts` (token/cookie), `lib/feed.ts` (RSS XML) — each unit-tested with Vitest. Next.js route handlers, server actions and pages are thin wrappers over them. `proxy.ts` (Next 16's renamed middleware, Node runtime) gates the UI.

**Tech Stack:** Next.js 16 (App Router, TypeScript, `output: "standalone"`), Tailwind, `react-markdown` + `remark-gfm`, Vitest, Docker (`node:22-alpine`), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-29-notefeed-design.md`

## Global Constraints

- Node ≥ 20.9 locally (Next 16 floor); Docker/CI use Node 22.
- No npm on this host: run `corepack enable npm` once (or `apt-get install -y npm`) before Task 1.
- Only runtime deps beyond the scaffold: `react-markdown`, `remark-gfm`. Dev: `vitest`. No feed library, no auth library.
- Env: `NOTEFEED_TOKEN` (required), `DATA_DIR` (default `/data`), `PUBLIC_URL` (default derived from request), `NOTEFEED_TITLE` (default `notefeed`). Read env at call time, never at module load (tests set it per test).
- Note body limit: 100 KB = `102400` UTF-8 bytes. Feed: newest `50`.
- id regex: `^\d{8}T\d{6}Z-[a-z0-9-]+$`. Cookie name: `nf_session`.
- Image: `ghcr.io/marceltov/notefeed:latest` and `:sha-<short>`. License MIT.
- Pages/routes that read disk: `export const dynamic = "force-dynamic"`.

## Review Focus

1. **`curl --data-binary @note.md` sends `Content-Type: application/x-www-form-urlencoded`** — the spec's headline curl example must work, so that type (and a missing type) is treated as raw markdown, not `415`. Test in Task 5.
2. **Non-ASCII titles** (`# Über Backups`, emoji-only) — slug strips diacritics (`uber-backups`), falls back to `note`; id still matches the regex. Test in Task 2.
3. **CRLF / BOM bodies** from Windows tools — title extraction ignores `\r` and a leading `﻿`; file content still byte-identical. Test in Task 2.
4. **Fresh volume / missing `DATA_DIR`** — `listNotes` returns `[]`, `createNote` creates the dir. Test in Task 2.
5. **Multibyte body near the limit** — limit counts bytes, not chars: 102400 bytes accepted, 102401 rejected. Test in Task 2 (`createNote`) and Task 5 (`413`).

### Task 2: Note storage — `lib/notes.ts`

**Files:**
- Create: `lib/notes.ts`, `lib/notes.test.ts`

**Interfaces:**
- Produces:
  ```ts
  export type Note = { id: string; title: string; markdown: string; createdAt: Date };
  export const MAX_BYTES = 102400;
  export class NoteTooLargeError extends Error {}
  export class EmptyNoteError extends Error {}
  export function extractTitle(markdown: string): string;
  export function slugify(title: string): string;
  export function isValidId(id: string): boolean;
  export function createNote(markdown: string, now?: Date): Promise<Note>;
  export function listNotes(limit?: number): Promise<Note[]>;   // default 50
  export function getNote(id: string): Promise<Note | null>;
  ```

Each test sets `process.env.DATA_DIR` to a fresh `fs.mkdtemp` dir in `beforeEach`.

- [ ] **Step 1: Write failing tests** in `lib/notes.test.ts`:
  - `extractTitle`: `"# Backup finished\nbody"` → `"Backup finished"`; `"\n\n- **hello** world"` → `"hello world"`; `"> quoted"` → `"quoted"`; `""` / `"   \n"` → `""`; 150-char line → length 100; `"﻿# Title\r\nbody"` → `"Title"`.
  - `slugify`: `"Backup finished!"` → `"backup-finished"`; `"Über Backups"` → `"uber-backups"`; `"🎉🎉"` → `"note"`; `""` → `"note"`; 80-char title → ≤ 50 chars, no trailing `-`.
  - `isValidId`: accepts `"20260929T140512Z-backup-finished"`; rejects `"../etc/passwd"`, `"20260929T140512Z-a/../../x"`, `"20260929T140512Z-A"`, `""`.
  - `createNote("# Backup finished\nok", new Date("2026-09-29T14:05:12Z"))` → id `"20260929T140512Z-backup-finished"`, `createdAt` equals that date, file `<DATA_DIR>/<id>.md` bytes equal input.
  - Collision: two creates, same `now`, same title → second id ends `-2`, third `-3`; first file unchanged.
  - CRLF body `"# T\r\nx\r\n"` stored byte-identical.
  - Empty/whitespace body → throws `EmptyNoteError`; `"é".repeat(51200)` (102400 bytes) OK; one more ASCII char → throws `NoteTooLargeError`.
  - `DATA_DIR` pointing at a not-yet-existing subdir: `listNotes()` → `[]`; `createNote` succeeds.
  - After the collision test, the dir contains only `.md` files (temp files are always cleaned up).
  - `listNotes`: 3 notes at different seconds → newest first; `listNotes(2)` length 2; a stray `.abc.tmp` and `README.txt` in the dir are ignored.
  - `getNote("../x")` → `null` without touching disk; unknown valid id → `null`; existing id → note with same markdown and title.
- [ ] **Step 2:** `npx vitest run lib/notes.test.ts` → FAIL (module not found).
- [ ] **Step 3: Implement `lib/notes.ts`.** Decisions the tests don't force:
  - `dataDir()` = `process.env.DATA_DIR ?? "/data"`, read per call.
  - `extractTitle`: strip leading BOM, split on `/\r?\n/`, first line matching `^#\s+` wins, else first non-empty line; strip leading markers `/^([#>*+-]|\d+\.)\s*/` repeatedly and inline `*`, `_`, `` ` ``; trim; slice(0, 100).
  - `slugify`: `normalize("NFKD")`, drop `\p{M}`, lowercase, `/[^a-z0-9]+/g` → `-`, trim dashes, slice(0, 50), trim trailing dash, `|| "note"`.
  - id timestamp: `now.toISOString()` → `YYYYMMDDTHHMMSSZ` (drop `-`, `:`, millis).
  - Write algorithm (atomic + never overwrite): `mkdir -p`; write to `.<random>.tmp` in the dir; loop suffix `""`, `-2`, `-3`…: `fs.link(tmp, final)`, on `EEXIST` try next suffix; `finally` unlink tmp. Any other error propagates (route maps to 500).
  - `listNotes`: `readdir` (ENOENT → `[]`), keep names where `isValidId(name.slice(0,-3))` and `.md`, sort desc, read first `limit`.
  - `createdAt` parsed from the id prefix.
- [ ] **Step 4:** `npx vitest run lib/notes.test.ts` → PASS; `npm run typecheck` → clean.
